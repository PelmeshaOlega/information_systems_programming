# information_systems_programming
Репозитория для лабораторных работ по Программированию информационных систем.

Основные команды для гита:   
git add - добавление файла в репозиторий   
git commit это сохранение данных в локальном репозитории. (надо посмотреть что это всё делает)   
git push отправка изменений на удалённый сервер  
git pull скачивание изменений с удалённого сервера
