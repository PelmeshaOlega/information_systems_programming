# information_systems_programming
Репозитория для лабораторных работ по Программированию информационных систем.

Основные команды для гита: 
git add - добавление файла в репозиторий  \n
git commit -m это сохранение данных в локальном репозитории. (надо посмотреть что это всё делает) \n
git push отправка изменений на удалённый сервер \n
git pull скачивание изменений с удалённого сервера \n
